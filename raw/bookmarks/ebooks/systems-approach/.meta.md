# Computer Networks: A Systems Approach

**Authors:** Larry Peterson, Bruce Davie
**Source:** [book.systemsapproach.org](https://book.systemsapproach.org/)
**License:** CC BY 4.0 / Open Source

## Book Overview

A systems approach to computer networking, teaching how networks are built and how protocols work together. Covers physical to application layers with emphasis on design trade-offs and implementation.

## Chapter Structure

1. **Foundation** - Problem statement, requirements, architecture, software, performance
2. **Direct Links** - Encoding, framing, error detection, reliable transmission, Ethernet, wireless
3. **Internetworking** - Switching, IP, routing
4. **Advanced Internetworking** - Global Internet, IPv6, multicast, MPLS, mobile IP
5. **End-to-End Protocols** - UDP, TCP, RPC, RTP
6. **Congestion Control** - Resource allocation, queuing, TCP CC, QoS
7. **End-to-End Data** - Presentation formatting, multimedia
8. **Network Security** - Trust, cryptography, key distribution, authentication
9. **Applications** - Traditional, multimedia, infrastructure, overlays
