# 4.2 负载均衡器总体功能

现代负载均衡器的功能已远超其初衷。本节介绍负载均衡器的常见功能。

## 4.2.1 服务发现

服务发现是负载均衡器识别后端服务器的机制，常见方式包括：

- **静态配置文件**：手动维护配置
- **DNS**：SRV 记录或 A 记录形式
- **服务注册中心**：如 Zookeeper、Etcd、Consul 等
- **服务网格数据平面 API**：xDS 协议

## 4.2.2 健康检查

健康检查评估后端服务器是否能正常处理请求：

- **主动健康检查**：定期发送探测请求
- **被动健康检查**：监控请求响应状态

## 4.2.3 粘性会话

确保同一会话的请求路由到相同后端服务器。基于 HTTP cookies、客户端地址或请求头实现。"设计具有该特性的系统时，需要格外谨慎！"

## 4.2.4 TLS 卸载

负载均衡器统一处理 TLS 加密/解密和证书管理。"这样做的好处是：减轻后端负载、减少运维负担、提升请求效率。"

## 4.2.5 安全和 DDoS 防御

作为集群唯一入口，负载均衡器是系统安全的第一道防线，支持 IP 黑/白名单、流量限速、请求鉴权、WAF 等功能。

## 4.2.6 可观测性

四层负载均衡器关注连接、流量、延迟；七层负载均衡器关注 HTTP 请求、错误码、会话保持等应用层数据。

## 4.2.7 负载均衡

负载均衡调度算法包括：

- **轮询算法**：简单平均分配
- **最小连接算法**：分配到连接数最小的服务器
- **一致性哈希算法**：保证同一特征值请求落在相同服务器
- **随机算法**：概率论保证长期趋于平均分配

考虑服务器处理能力差异，还有加权负载均衡算法补充。
