# 3.4 内核旁路技术

## 概述

内核旁路（Kernel Bypass）技术是一种绕过 Linux 内核协议栈，直接在用户空间处理网络数据包的技术。这种技术可以显著提升网络性能，适用于高吞吐量的网络场景。

## 主要技术

- **DPDK**：数据平面开发套件
- **XDP**：快速数据路径（eXpress Data Path）
- **RDMA**：远程直接内存访问
