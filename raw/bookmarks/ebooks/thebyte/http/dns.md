# 2.3 域名解析的原理与实践

## DNS 概述

域名系统（DNS）是互联网的核心服务，负责将域名解析为 IP 地址。其架构呈层次化树形结构，从根域名服务器到 TLD 域名服务器，再到权威域名服务器。

## DNS 解析流程

当用户在浏览器中输入域名时，系统会依次查询：
1. 浏览器缓存
2. 系统缓存（hosts 文件）
3. 本地 DNS 解析器
4. 根域名服务器
5. TLD 域名服务器
6. 权威域名服务器

## DNS 记录类型

常见的 DNS 记录类型包括：
- **A 记录**：将域名指向 IPv4 地址
- **AAAA 记录**：将域名指向 IPv6 地址
- **CNAME 记录**：将域名指向另一个域名
- **MX 记录**：指定邮件服务器
- **TXT 记录**：用于验证和 SPF 记录
