# 第四章：存储与检索

> 计算机的主要功能并不是传统意义上的计算，而是归档系统。

## OLTP 系统的存储与索引

### 简单数据库

```bash
db_set () {
  echo "$1,$2" >> database
}

db_get () {
  grep "^$1," database | sed -e "s/^$1,//" | tail -n 1
}
```

## 日志结构存储

### SSTable

排序字符串表，确保键值对按键排序。

### LSM 存储引擎

1. 写入添加到内存有序映射
2. 内存表超过阈值时，写入磁盘作为 SSTable
3. 读取时在内存表和最新磁盘段中查找
4. 后台合并和压实

### 布隆过滤器

快速、近似检查键是否存在于特定 SSTable 中。

## B 树

按键排序，允许高效的键值查找和范围查询。

### B 树可靠性

- 预写日志 (WAL)
- 写时复制

### B 树 vs. LSM 树

- LSM 树：写入友好
- B 树：读取更快

## 列式存储

面向列的存储适合分析查询。

### 列压缩

位图编码是数据仓库中特别有效的技术。

## 多维索引与全文索引

### 倒排索引

键是词项，值是包含该词项的文档 ID 列表。

### 向量嵌入

语义搜索，使用向量索引如 HNSW。

## 总结

- OLTP: 大量请求，每次读写少量记录
- 分析系统: 扫描大量记录的复杂读取查询
