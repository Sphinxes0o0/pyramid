# 内存管理

This page is a table of contents for a Linux kernel memory management documentation site. The content shows organized links covering:

**Key Topics Include:**
- Kernel page table evolution (内核页表成长记)
- Memory bottom-up view (自底而上话内存) - including e820, memblock, page allocator, buddy system, SLUB
- Page structures (folio, compound pages, Node-Zone-Page hierarchy)
- Virtual memory space and page faults
- Reverse mapping (rmap)
- Transparent Huge Pages (THP, mTHP)
- NUMA policies and balancing
- Memory reclaim and swap
- Memory cgroups (memcg)
- Performance optimization and batch processing
- Testing and monitoring tools (meminfo, vmstat, pagemap, etc.)
