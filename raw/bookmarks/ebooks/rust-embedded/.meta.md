# Rust Embedded Drivers (RED) Book

Learn embedded Rust driver development through practical projects building drivers for real hardware devices.

## Chapters

1. **Introduction** - Prerequisites and overview
2. **DHT22** - Temperature & Humidity Sensor driver
3. **MAX7219 LED Display** - LED matrix and 7-segment display driver
4. **Embedded Graphics** - Using embedded-graphics crate with MAX7219
5. **Real Time Clock** - DS1307 and DS3231 RTC chips with full HAL implementation
